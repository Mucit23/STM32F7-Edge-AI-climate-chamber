# docs

- `index.html`: uzaktan izleme sayfası (GitHub Pages bu klasörden yayınlanır).
  Adres satırından başka bir kullanıcı/grup seçilebilir: `index.html?user=Mucit23&group=iklim`
- Test protokolü, bağlantı şemaları ve notlar buraya eklenecek.

- `Proje_Defteri_Edge_AI_Iklim_Kabini.docx`: deney düzeneği, yazılım, veri formatı, test günlüğü, ölçülmüş parametreler ve karar günlüğü (tez için).
  `proje_defteri_build.js` ile `sekiller/` klasöründeki grafiklerden yeniden üretilir (`node proje_defteri_build.js cikti.docx`).
